# conta-horas

Script de uso pessoal: soma as horas do log de apontamentos por projeto.

```bash
python conta_horas.py horas.log
python conta_horas.py horas.log --mes 2026-10
```

Saída hoje é só no terminal. O fechamento do mês é enviado para o financeiro, que pediu o
relatório em planilha (eles abrem no Excel) para não precisar redigitar.
