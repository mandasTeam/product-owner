# Engenharia de Requisitos · Trabalho N1

Prof. Marcos Vieira · 4º semestre · Entrega: 14/11/2026

## Objetivo

Desenvolver, em equipes de 3 integrantes, um sistema web de reserva de salas de estudo da
biblioteca do campus.

## O sistema deve

1. Permitir que o bibliotecário cadastre salas (nome, capacidade, recursos disponíveis).
2. Permitir que o aluno reserve uma sala por até 2 horas seguidas, informando a matrícula.
3. Impedir reservas sobrepostas da mesma sala.
4. Gerar o relatório de ocupação semanal das salas.

## Entrega

- Código no GitHub, com README explicando como executar.
- Cada integrante deve ter commits próprios no repositório.
- Apresentação de 10 minutos em sala.
